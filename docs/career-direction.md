# Career direction

## Current professional position

Fred is an experienced frontend developer with strong commercial experience in:

- React
- TypeScript
- Next.js App Router
- JavaScript and browser APIs
- Headless ecommerce
- BigCommerce
- Headless CMS platforms
- REST and GraphQL integrations
- Third-party services
- Technical decision-making
- Code review and mentoring
- Owning work from requirements through release

His work has involved complex multi-region ecommerce applications,
authentication, CMS integrations, search and recommendations, customer-specific
catalogues, middleware, analytics, deployment workflows, and production support.

## Career direction

Fred is moving towards being a product-focused full-stack engineer.

His current growth priorities are:

- Node.js
- Server-side TypeScript
- API design
- Backend architecture
- Databases and data modelling
- Authentication and authorisation
- Testing and observability
- System design
- AI-enabled product development
- LLM integrations and agentic workflows

He is not abandoning frontend development. His goal is to combine advanced
frontend expertise with meaningful backend ownership.

## Roles the site should support

The portfolio should appeal primarily to employers hiring for:

- Senior Frontend Engineer
- Frontend-focused Full Stack Engineer
- Product Engineer
- Senior Software Engineer with strong frontend expertise
- Technical Lead
- Full-stack TypeScript Engineer

Particularly attractive roles include:

- Product companies rather than purely brochure-site work
- React and TypeScript
- Node.js or comparable backend exposure
- Ownership across the product lifecycle
- API and integration work
- Architectural input
- Mentoring or progression towards technical leadership
- Remote-first work, ideally with limited UK office attendance
- Products with a meaningful purpose, including tech-for-good

## Positioning

The core professional story is:

> A senior frontend engineer with substantial experience delivering complex
> React and Next.js products, now expanding deeper into backend engineering
> and end-to-end product development.

Backend learning should be presented as deliberate professional growth, not as
a lack of seniority.

## Portfolio priorities

The site should increasingly demonstrate:

5. Product thinking and trade-off analysis.
6. Testing and maintainability.
7. AI-enabled product experiments where genuinely useful.
