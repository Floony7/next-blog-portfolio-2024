# AGENTS.md

## Project purpose

This is Fred's personal developer portfolio and blog.

Before making changes involving positioning, biography, projects, skills,
case studies, navigation, homepage content, or career-related copy, read:

- `docs/career-direction.md`

Changes should support the professional direction described there.

## Product principles

- Present Fred as a senior frontend engineer growing into a product-focused
  full-stack engineer.
- Do not position him as a junior backend developer.
- Lead with strong commercial React, TypeScript, Next.js, ecommerce,
  headless CMS, API integration, and technical leadership experience.
- Show backend development as an intentional expansion of an established
  engineering skill set.
- Prefer evidence through projects and case studies over unsupported claims.
- Prioritise clarity, credibility, and practical engineering depth.
- Avoid generic personal-brand language and exaggerated claims.

## Technical preferences

- TypeScript
- Next.js App Router
- React
- Server Components by default
- Accessible semantic HTML
- Maintainable CSS
- Strong typing; avoid unnecessary `any`
- Keep components focused and avoid premature abstraction
- Run linting, type-checking, and relevant tests after changes

## Working method

For substantial changes:

1. Inspect the existing implementation.
2. Explain the proposed approach briefly.
3. Preserve the established visual language unless redesign is requested.
4. Implement the change.
5. Verify responsive behaviour, accessibility, linting, and types.
6. Summarise what changed and any remaining trade-offs.
